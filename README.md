# Cells

A simple [life-like cellular automaton](https://en.wikipedia.org/wiki/Life-like_cellular_automaton) simulator.

## Features

[x] Pausing and resuming simulation
[ ] Step-by-step simulation
[ ] Loading initial cells configuration from a file
[ ] Setting rules via command line option or a header line in file
[ ] Ability to toggle cell state

## Usage

```bash
cargo run
```
